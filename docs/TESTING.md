# 测试与排查

## 自动测试

Python 测试覆盖独立分钟设置、首次成功起算、不重复续期、动态缩短、最早停止时间、间隔修改、重试退避、断线暂停新轮次、持久命令去重、客户端重启待命。子进程测试启动假的 Codex 和其子进程，验证停止确实清理进程树；不会调用真实模型。

Cloudflare 测试在本地 workerd 中运行真实 SQLite Durable Object 与 WebSocket，验证授权、配对码并发一次性消费、Telegram 去重、指定机器路由、参数隔离、离线停止意图、定时错过不补发。

回归测试还覆盖连续重连失败的离线期限、网络发送阻塞时的本地到期、旧连接迟到事件、重新绑定的状态隔离、TG 回执/通知失败及认证期间设备被移除。

```sh
python -m pytest -q
cd cloud
npm run check
npm test
npx wrangler deploy --dry-run
```

开发依赖锁在 `cloud/package-lock.json`；`npm ci` 保持一致。不要使用 `npm audit fix --force` 自动大范围降级或改写版本。

## 真实使用验收

自动测试不会验证真实 Bot Token、你的 Cloudflare 账户权限或 Codex 账户的模型可用性。部署后用两台 Windows 和一台 Mac 验证：

1. 三台分别命名、选会话，给不同的保持时长与发送间隔。
2. 首次成功时开始计时，持续轮次不续期，到期停止。
3. 运行中把保持时长缩短到已超时，确认立即停止。
4. 新建会话执行中点停止，再确认不会多建会话。
5. 断网超过一分钟不再启动新轮次；重连不会补发或重置计时。
6. 关闭终端仍可操作；退出登录停止，重新登录上线待命。
7. 修改机器名称、批量停止、创建和取消定时任务；移除设备后凭据失效。

## 常见问题

| 现象 | 检查 |
| --- | --- |
| Bot 没响应 | Worker 地址、Secrets、Webhook、用户/聊天 ID；同 Bot 的旧轮询脚本应停止。 |
| 安装下载 404 | `RELEASE_TAG` 对应的正式 Release 与安装包是否已发布。 |
| 配对失败 | 配对码是否十分钟内、是否已用过；Worker 是否部署完整。 |
| CLI 登录失败 | 在同一系统用户下运行 `codex login`；桌面端登录不能替代这里的实际检查。 |
| 找不到 Codex | 使用“诊断”，检查安装路径或设置 `ANYBOT_CODEX`。 |
| 会话被占用 | 在 Codex 桌面端关闭对应会话后重试，不删除写锁。 |
| 一直无响应但不报成功 | 只有结构化完成事件才算成功；可在 TG 停止后检查本机 Codex。 |
| 日常状态离线 | Worker WSS 连通性、电脑休眠状态、后台任务、代理设置、Cloudflare 免费额度。 |
| 更新失败 | 本地 `agent.log`、GitHub Release 校验清单、`previous.json`；必要时回退版本。 |
| 服务器未确认停止 | 离线设备无法收到即时操作；停止意图已保存，上线后同步。本机已知的截止时间仍有效。 |

客户端 WebSocket 使用系统代理环境变量；连接异常可检查 `HTTPS_PROXY` / `NO_PROXY`。安装器与 Codex 的网络链路也需各自可达，不会自动修改系统代理。
